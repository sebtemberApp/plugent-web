# Plugent brand

The logo is a socket with a small neural network inside: two hollow rings (the socket's holes) and two
nodes, linked around the edge and across the middle. It sits beside the name, set in Manrope ExtraBold
(Sebtember's typeface) and converted to outlines, so the files need no font.

| File | Use |
|---|---|
| `public/logo-navy.svg` | logo on light backgrounds |
| `public/logo-light.svg` | logo on dark backgrounds |
| `public/mark.svg`, `public/mark-light.svg` | the socket alone, on light / dark |
| `public/icon.svg` | browser tab icon; switches to the light plate in a dark browser theme |
| `public/apple-icon.png` (180), `public/icon-192.png`, `public/icon-512.png` | home-screen and app icons |

Colours: navy `#16152E`, pink `#FF0058`, light `#F5F5F7` (Sebtember's navy and pink).
The drawings were generated by a script, kept with the design notes in the project files
(`plugent/design/`), so a change to the mark is made there and the files are regenerated.
